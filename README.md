🚗 Drive Easy – Vehicle Rental System

Drive Easy is a web-based Vehicle Rental System designed to make vehicle booking simple, convenient, and user-friendly. It allows customers to explore available vehicles, view their details, and manage their bookings. It also provides an admin panel to manage vehicles and handle system operations.

🌟 Project Overview
  Drive Easy aims to provide an easy and efficient platform for renting different types of vehicles, including cars, SUVs, bikes, and scooters.
  The project includes two main modules:
  Client Side: Allows users to explore vehicles, book vehicles, manage their profiles, and view booking details.
  Admin Side: Allows administrators to manage vehicles and control rental system operations.

✨ Features

👤 Client Side
  User-friendly homepage.
  Browse available vehicles.
  Search and filter vehicles.
  View detailed vehicle information.
  Book vehicles easily.    
  Manage user dashboard.  
  View booking history.
  Update profile information.
  Change password.
  Contact and support section.
  Logout functionality.


🔐 Admin Side
  Admin login system.
  Admin dashboard.
  Add new vehicles.
  Update vehicle details.
  Delete vehicles.
  Manage vehicle listings.
  Form validation.
